# Prosek Volejbal – mobilní oprava

Nahraj soubory přímo do kořene repozitáře:
index.html, style.css, app.js, manifest.json, data.json, sw.js, icon-192.png, icon-512.png, README.md.

Opravy:
- funguje lépe na iPhone/iPadu
- přidáno Zpět mezi stránkami
- detail zápasu má Zpět
- funguje tlačítko Zpět v Safari
- aplikace používá aktuální datum
- offline cache pro základní aplikaci
- Web má záložní tlačítko „Otevřít web v Safari“, pokud volejbalek.cz nepovolí iframe.
